What it looks like in game

Storyline replaces the classic quest window with a cinematic dialog: the NPC and your character face each other while the story text plays out. This build brings the Cataclysm and Warlords-era design to the 3.3.5a client.

What this fork fixes

  • The green check button now accepts the quest. (v3.3.1)
  • The X button closes the dialog.
  • The dim slider works as expected.
  • Scrolling the mouse wheel no longer resizes the model.
  • The NPC and your character face the right direction.

Planned, not released yet

  • Per-zone backgrounds, starting with vanilla locations, with an option to turn them on or off. Right now the background is only tinted by faction.
  • A friendship and reputation bar like the one in Retail.

See the full history in the changelog on GitHub.

Install in four steps

  1. Download the addon

    Open the repository, choose Code, then Download ZIP. Go to the repository

  2. Extract and rename the folder

    Rename the extracted folder to Storyline so it matches Storyline.toc.

  3. Copy it into AddOns

    World of Warcraft/Interface/AddOns/Storyline

  4. Start the game

    Make sure Storyline is ticked on the AddOns screen at character select, then talk to any quest giver.

Found a bug? Open an issue on GitHub with the addon version and what you clicked.
